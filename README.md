# Modbus Studio

一个以接收和调试体验为重点的 Modbus RTU 桌面工具。界面采用右侧功能选项卡，发送构造器只需填写业务字段即可自动生成地址、功能码、长度和 CRC。

## 功能

- 串口热插拔自动检测、常用串口参数、连接状态与接收统计
- RTU 帧静默分包、CRC 校验、常用功能码摘要解析
- 原始 HEX / 帧列表 / 字节统计三种视图
- 地址、功能码、CRC 状态和关键字过滤
- 类型化数据解析：uint/int 8/16/32、float32/float64、大小端、偏移、数量和缩放
- 解析通道采用类似 Keil Watch 的结构树：单个值直接作为变量，多个值展开为成员，节点可双击改名
- 波形支持“单窗口”和“A/B 上下分屏”两种布局；分屏中的两个绘图区可分别右键绑定解析成员
- 波形支持滚轮横向缩放、Ctrl+滚轮纵向缩放、拖拽回看、双击复位和图例单击显隐
- 暂停显示后可悬停检查采样点，通过十字准线同时查看各可见通道的精确值
- 波形数据可后台导出为UTF-8 CSV，包含毫秒时间戳和各绑定通道列
- 响应驱动的 01/02/03/04 安全轮询，不会在上一响应未完成时盲发下一请求
- 轮询时帧列表固定为 RX、TX 两行，只刷新时间、摘要和原始帧，不产生滚屏日志
- 顶部暂停可冻结帧、解析值和波形显示，串口接收与安全轮询仍在后台继续
- 轮询固定行采用原位更新，底部最近帧使用固定宽度字段，避免高频刷新闪烁
- 解析页支持一键清空全部通道和波形绑定
- 自动构帧：读线圈、读输入、读保持/输入寄存器、写单个/多个线圈或寄存器
- 独立类型化写入页：直接输入整数/浮点/线圈值，自动编码字节序并选择05/06/0F/10功能码
- 安全轮询期间可插队写入：等待当前读响应后发送写命令，写响应成功、异常或超时后自动恢复轮询
- 自动 CRC、循环发送、串口配置持久化
- 默认 VOFA+ 灰白配色，可在串口设置中切换深色模式
- 参数面板的选项卡在右侧竖向排列，但标签文字保持横向阅读
- 主区视图按钮会一次性打开最相关的右侧页，之后可自由切换，不会锁定
- 串口发送使用有界线程队列，日志和统计批量刷新，长时间运行采用有界缓存
- 工程配置可导出/导入可读 JSON：还原串口、轮询、解析结构、波形绑定、写入/构帧参数和界面状态
- JSON 内置字段语义说明，可直接交给 AI 修改；导入前完整校验，且不会自动连接、轮询或写设备

## 稳定性与线程模型

- 串口读取、RTU静默分帧和实际写串口运行在独立线程；发送使用256项有界队列，突发写入不会直接阻塞界面。
- CSV导出运行在独立线程，通过线程安全快照和临时文件原子替换完成，导出期间轮询和波形记录可继续工作。
- Qt界面、解析结果展示和绘图保留在主线程，避免跨线程操作控件导致随机崩溃；波形重绘限制为约30 FPS，但每个有效样本仍会被记录。
- 串口连续接收缓冲限制为64 KiB，原始待显示日志限制为5000行，帧缓存默认5000帧，波形每通道5000点，CSV记录最多20万行。
- 暂停只冻结显示和波形追加，串口收发与响应驱动轮询不会停止。

## 启动

```powershell
pip install -r requirements.txt
python main.py
```

## 打包 Windows 单文件 EXE

首次打包先安装发布依赖：

```powershell
python -m pip install -r requirements-build.txt
```

生成/更新程序图标：

```powershell
python icon.py
```

打包为不显示控制台的单文件程序：

```powershell
python build.py
```

输出文件为 `dist/ModbusStudio.exe`，可复制到未安装Python的64位Windows电脑直接运行。构建配置只包含PySide6 Essentials所需的Core/Gui/Widgets，并明确排除PyQt和PySide6 Addons。需要彻底清理旧构建缓存时使用 `python build.py --clean`；该选项只会删除本项目下的 `build` 和 `dist` 目录。

pytest -q

## 工程 JSON 与 AI 修改

在右侧“设置 → 工程 JSON”中可以导出或导入配置。导出的文件包含串口参数、轮询范围、解析变量/结构、成员名称、波形绑定、接收过滤、写入和构帧参数，以及主题、当前页面、窗口大小和波形缩放。

JSON 不包含历史接收帧和波形采样。导入后串口保持断开、轮询和循环发送保持停止，不会因为打开配置而修改设备。如果 JSON 字段缺失、类型错误、地址越界或波形引用了不存在的成员，软件会拒绝整个文件并显示具体字段；可以把 JSON 和错误信息一起发给 AI 修复。

## 通用轮询与波形

1. 按设备手册选择串口参数并连接。
2. 在“轮询”中设置从站、01/02/03/04功能码、起始地址、数量和间隔。
3. 在“解析”中创建变量或结构。解析数量为1时通道本身就是变量；数量大于1时自动展开成员，双击节点即可改名。
4. 点击主区“实时波形”会自动打开右侧“解析”；展开结构后，右键成员选择“添加到波形调试”，父节点右键可整组添加。
5. “成功”应持续增加，“超时/异常”应保持 0。

解析通道直接填写设备手册中的绝对寄存器地址。界面会按照数据类型自动设置地址步进并显示覆盖范围；例如连续float32地址依次为1103、1105、1107。uint8/int8可额外选择寄存器高字节或低字节。

“解析数量”表示数值个数而不是寄存器个数。添加数据区解析时，软件会自动扩大03/04轮询的寄存器数量以覆盖完整变量；轮询已经运行时从下一次请求生效。通道名称留空会按实际创建顺序生成“通道 1、通道 2……”且删除后不重复编号。

## 导出波形 CSV

1. 在“解析”结构树中右键绑定需要记录的成员变量。
2. 开始轮询；波形页顶部会显示已记录行数。
3. 点击“导出 CSV”并选择文件位置。导出在独立线程完成，不会中断串口轮询。
4. CSV第一列为毫秒时间戳，后续每列对应一个波形通道；不同帧没有更新的通道保持为空。

记录缓存最多保留最近20万行。清空波形会清除记录数据，但不会取消通道绑定。

独立只读硬件测试（不会修改寄存器）：

```powershell
python tools/rtu_read_test.py COM14 --function 3 --start 0 --quantity 10 --count 100 --interval 0.05
```
