# Modbus Studio

一个以接收和调试体验为重点的 Modbus RTU 桌面工具。界面采用右侧功能选项卡，发送构造器只需填写业务字段即可自动生成地址、功能码、长度和 CRC。

## 功能

- 串口热插拔自动检测、常用串口参数、连接状态与接收统计
- RTU 帧静默分包、CRC 校验、常用功能码摘要解析
- 原始 HEX / 帧列表 / 字节统计三种视图
- 地址、功能码、CRC 状态和关键字过滤
- 类型化数据解析：uint/int 8/16/32、float32/float64、大小端、偏移、数量和缩放
- 解析通道可直接绑定到多通道滚动波形
- 响应驱动的 01/02/03/04 安全轮询，不会在上一响应未完成时盲发下一请求
- 轮询时帧列表固定为 RX、TX 两行，只刷新时间、摘要和原始帧，不产生滚屏日志
- 自动构帧：读线圈、读输入、读保持/输入寄存器、写单个/多个线圈或寄存器
- 自动 CRC、循环发送、串口配置持久化
- 默认 VOFA+ 灰白配色，可在串口设置中切换深色模式
- 参数面板的选项卡在右侧竖向排列，但标签文字保持横向阅读

## 启动

```powershell
pip install -r requirements.txt
python main.py
```

## 测试

```powershell
pytest -q
```

配置保存在系统用户配置目录中，不写入工程目录。

## 通用轮询与波形

1. 按设备手册选择串口参数并连接。
2. 在“轮询”中设置从站、01/02/03/04功能码、起始地址、数量和间隔。
3. 在“解析”中创建通道。选择类型、字节序、数据区字节偏移、数量和缩放倍率。
4. 勾选“绑定到实时波形”，再开始安全轮询。
5. “成功”应持续增加，“超时/异常”应保持 0。

解析偏移以响应的数据区为起点。例如读取一块保持寄存器时，第一个寄存器偏移为0，第二个为2；从第三个寄存器开始解析一个float32时，偏移填4、类型选择float32。

独立只读硬件测试（不会修改寄存器）：

```powershell
python tools/rtu_read_test.py COM14 --function 3 --start 0 --quantity 10 --count 100 --interval 0.05
```
